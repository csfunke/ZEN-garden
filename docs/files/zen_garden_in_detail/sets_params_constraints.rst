.. _notation.notation:

####################################
Notation
####################################

This page defines the mathematical notation used throughout ZEN-garden. The
tables are generated from the declarative model component classes, which are
the source of truth for component names, symbols, dimensions, descriptions,
and unit categories. Entries are listed alphabetically by their mathematical
symbols.

.. raw:: html

   <style>
   #notation table.docutils {
       font-size: 0.82rem;
   }
   </style>

**Naming conventions.** Code names use ``snake_case`` and set names begin with
``set_``. Mathematical sets use calligraphic uppercase letters, parameters use
lowercase letters, and variables use uppercase letters. Superscripts describe
roles or types; subscripts are indices and are omitted when implied—for example,
:math:`t \in \mathcal{T}_y` already identifies year :math:`y`.
